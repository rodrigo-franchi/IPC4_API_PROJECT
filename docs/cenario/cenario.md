# Cenário do Projeto

Você atua como gerente de projetos responsável pelo desenvolvimento de uma API REST para gestão de clientes, baseada em Node.js, Express e MongoDB.
O sistema inclui funcionalidades como cadastro de clientes, atualização de dados, exclusão lógica (soft delete), busca por nome e e-mail, além de registro de logs e cobertura de testes automatizados.

O projeto encontra-se em fase intermediária de desenvolvimento, com parte das funcionalidades já implementadas e outras ainda em progresso.

Nas últimas semanas, surgiram os seguintes desafios:

- O excesso de stakeholders, principalmente advogados e escritórios de advocacia, tem gerado conflitos frequentes na definição e na mudança de requisitos, causando retrabalho e dificuldade de priorização.
- Os dados armazenados pela API precisam atender aos requisitos da LGPD, exigindo revisão de políticas de coleta, armazenamento, acesso, auditoria e retenção de informações.
- O time de desenvolvimento sofreu perda de profissionais e precisou contratar novos integrantes, impactando a produtividade, a curva de aprendizado e os prazos planejados.

Considere ainda que:

- A equipe é composta por 4 desenvolvedores e 1 tester.
- A adequação à LGPD é crítica para a entrega e para a continuidade do projeto.
